# 穿搭工作台

上传一张喜欢的穿搭照，拆出它的服装配色、比例和配饰，再得到三套能照着穿的日常搭配：原样、好穿、跳色。效果图可以用你手头任何能生成图片的 AI 来画。搭配可以收藏、按天气和场合筛选、保存成海报。

照片只在你自己的设备上识别，不会上传。

## 准备

- 一台电脑，装有 [Node.js](https://nodejs.org) 20.11 或更新版本。不需要安装其他依赖。
- 较新的 Chrome 浏览器（需要支持 WebGL，大多数电脑默认支持）。
- 想自动生成效果图的话：一个你已经在用、能生成图片的 AI 工具。没有也能用，见下文「效果图」。

## 最简单的用法：交给你的 AI 助手

如果你在用能操作电脑的 AI 助手（例如 Codex、Claude Code 等），把整个文件夹交给它，然后发这段话：

```text
请阅读这个项目里的 skill/SKILL.md，按说明在我的电脑上启动穿搭工作台。
再按 skill/ADAPTERS.md 检查我电脑上有没有可以接入的生图能力；需要真实生成图片或可能产生费用时，先问我。
```

AI 助手会启动工作台并打开浏览器，检查能不能接入自动生成，接不上也不影响其他功能。

## 自己启动

在本项目的 `skill/` 文件夹里打开终端，运行：

```sh
node server/start.mjs
```

浏览器会自动打开工作台。保持这个终端窗口开着；关闭时按 Control+C，或在另一个终端运行：

```sh
node server/stop.mjs
```

浏览器没有自动打开时，双击启动输出里 `launcher` 给出的 `open.html` 文件。只想启动、不自动打开浏览器时，运行 `node server/start.mjs --no-open`。

工作台只在本机地址 `127.0.0.1:18438` 上运行，同一网络里的其他设备访问不到。

## 只用网页

`skill/web/` 是纯静态网页，放到静态网站上也能用，不需要 Node.js；这种方式没有自动生成，效果图按下面「效果图」的三步来。直接双击 `index.html` 打不开（浏览器不允许本地文件加载识别模型），需要通过网址访问。

## 效果图

每套搭配下面有「生成效果图」：

1. 复制提示词。
2. 粘贴到任何能生成图片的 AI，例如豆包、即梦、ChatGPT、Gemini。颜色偏差大时，可以把工作台给出的色卡一起发过去。
3. 把生成好的图片传回这套搭配：拖入、粘贴或选择文件；在手机上用网页时从相册选择。

工作台会核对效果图里的颜色。这个核对只比较颜色是否接近，不检查衣服的位置、面积或多出来的颜色。

### 自动生成

如果你的电脑上有能在后台生图的工具，可以让 AI 助手按 `skill/ADAPTERS.md` 接入，之后上传照片就会自动生成 3 张效果图，可在网页的 SETTINGS 里关闭。

- 现成支持 **Codex**（需要用 ChatGPT 账号登录）。自动生成会消耗你的 Codex 额度；额度用完后，如果你买过加量包，会开始扣费。检测到 Codex 用 API 密钥登录时，工作台不会自动生成。
- 也可以让 **AI 助手在对话里代为生成**：在网页上点「用 AI 助手生成」，再回到对话告诉助手，它会在对话里画好交回。
- 其他命令行生图工具可以按 `skill/ADAPTERS.md` 写一个小的接入文件。

每家工具的费用以它自己的规则为准。

## 数据和备份

- 收藏和最近一次结果都保存在**当前浏览器**里。不同浏览器、不同网址或端口是分开的。
- 在收藏页可以「导出备份」（一个 JSON 文件，含图片），换电脑或换浏览器时到新地址「导入备份」，已有的条目会跳过。
- Safari 上一个网站 7 天没有打开，数据可能被清除。定期导出备份；在手机上用网页时，可以把它加到主屏幕。
- 关闭工作台不会删除浏览器里的收藏。`skill/.runtime/` 保存临时文件和运行记录（只有任务编号、状态和时间，没有照片），工作台下次启动时会清空其中的临时图片。

## 隐私

- 照片在你的浏览器里识别和取色，不发送给任何服务；网页不使用统计或埋点，也不向外部网址发请求。
- 复制给 AI 的只有搭配文字，以及你自己选择附上的色卡。
- 自动生成时，发给生图工具的也只有搭配文字。
- macOS 上浏览器打不开的 HEIC 照片，会交给本机系统自带的 `sips` 转换。

## 已知限制

- 识别需要浏览器支持 WebGL；不支持时网页会给出提示。
- 识别用的是人像分割模型，包、腰带、墨镜、首饰等小配饰可能漏识别或猜错品类，可以在页面上「添加配饰」或点品类修改。
- 秀场图里的蓬裙、羽毛、金属面料等，颜色占比可能不准；白衣在冷光下可能被叫成灰蓝。
- 颜色核对只比较颜色，不代表整套效果图都准确。

## 测试

在项目根目录运行：

```sh
node tests/run.mjs
```

测试只使用程序合成的数据和模拟的生图工具，不需要照片，也不会真的生成图片。
